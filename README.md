# batch-script
Windows Shutdown BAT Script

A simple Windows batch (.bat) script to shut down your Windows PC instantly or after a specified delay.

Features

Instant system shutdown

Scheduled shutdown with a timer

Simple and easy to use

No additional software required

Built-in Windows commands

Requirements

Windows 10 or Windows 11

Notepad or any text editor

Installation

Clone this repository or download the ZIP file.

Open Notepad.

Copy the shutdown script into the editor.

Save the file as Shutdown.bat.

Set Save as type to All Files
